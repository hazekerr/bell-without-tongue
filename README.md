# Колокол без Языка

Мрачный карточный roguelike-deckbuilder для телефона и браузера в горизонтальной ориентации. Умер, и забег начинается заново, но история остаётся. Смерть здесь двигает сюжет, а не просто сбрасывает прогресс.

> Срез v0.3: горизонталь, пиксель-арт (силуэты, 60 FPS), пролог, Круги I–III, четыре роли (Звонарь открывается после босса Круга II, Исповедник после финала среза), 88 карт, 19 врагов с анимированными силуэтами, события, лавка, Хроника и возвращение после смерти. Целевая длина полной игры: ~100 часов, семь актов.

## Идея в двух строках
- Забег: колода, здоровье, монеты и позиция на карте пропадают при смерти.
- Хроника (страницы истории, имена, видения, открытые карты) остаётся навсегда. Постоянной силы нет: прогресс игрока это только знание и новые карты.

Полный дизайн-документ: [docs/GDD.md](docs/GDD.md).

## Быстрый старт
```bash
npm install
npm run dev        # http://localhost:5173  (добавь ?debug для отладочных хуков)
npm test           # правила боя, забег, Хроника, контент
npm run sim        # симулятор баланса (бот проходит забеги)
npm run build      # PWA в dist/
```

Работает как PWA: открывается в браузере телефона, добавляется на главный экран, играется офлайн.

## Как выложить игру
В репозитории настроен деплой на GitHub Pages (`.github/workflows/pages.yml`). Один раз включите: Settings → Pages → Source: **GitHub Actions**. После этого каждый push в `main` собирает и публикует игру по адресу `https://hazekerr.github.io/bell-without-tongue/`. Запуск вручную: вкладка Actions → Pages → Run workflow.

## Устройство
| Папка | Что внутри |
|---|---|
| `src/engine` | Чистая игровая логика без DOM: бой, карты, враги, забег, события, Хроника, сохранение |
| `src/content` | Тексты и данные истории: страницы Хроники, разговоры в хабе |
| `src/art` | Пиксель-арт: движок спрайтов (`pixel.ts`), рукописные спрайты (`cast.ts`, `cast2.ts`), иллюстрации карт (`cardart.ts`), фоны (`scenes.ts`) |
| `src/ui` | Горизонтальный интерфейс на DOM + CSS, синтезатор музыки (Web Audio) |
| `tests` | Vitest: правила боя, инварианты Хроники, генерация карты |
| `scripts` | `sim.ts` (баланс), `land.cjs`, `land2.cjs`, `prologue.cjs` (скриншоты и прогон через Playwright, горизонтальный экран) |

## Ключевые правила
- **Три Голоса:** Удар, Оберег, Обряд. Если за ход сыграны карты всех трёх типов, срабатывает **Аккорд**. Эффект зависит от роли.
- **Дыхание:** 3 за ход, карт в руке 5.
- **Статусы:** Тлен, Кровь, Страх, Оковы. Намерения врагов всегда видны.
- **Роли:** Могильщик (Тлен + Могила), Свечница (Пламя + Кровь), Звонарь (Звон: каждая карта звенит, на шестом ударе колокол бьёт по всем). Исповедник (Долг: расписки в колоде как топливо, Аккорд исчерпывает Долг и бьёт по всем).

## Заказы
Перед спуском можно взять Заказ от жителей Сальвена (Ильза, Мёрк, Тин, Гаспар): необязательную цель забега. Награда разовая и только для этого забега (реликвия, исцеление, выбор редкой карты) плюс страница Хроники. Заказы от Тин и Гаспара предлагаются, только если вы знаете их имена.

## Управление (двумя руками, горизонталь)
Сцена всегда занимает весь экран без пустых полос. Левый большой палец: Дыхание, Аккорд и стопки. Правый: «Конец хода». Карты под обоими пальцами. Тап по карте поднимает её и показывает крупно. Второй тап или свайп вверх разыгрывает. Если целей несколько, потяни карту на врага или нажми на него. Долгое нажатие на врага показывает описание.
В портретной ориентации показывается просьба повернуть телефон.

## Баланс
Бот-симулятор (`npm run sim`) показывает нижнюю границу силы игрока. Текущие цифры лежат в `docs/GDD.md`, раздел «Баланс».

## Лицензия и ассеты
Весь арт и звук делаются кодом. Спрайты нарисованы вручную текстом, остальное собирается из деталей. Шрифты: Handjet, Press Start 2P и EB Garamond через `@fontsource` (SIL OFL).
