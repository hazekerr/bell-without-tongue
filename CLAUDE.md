# Инструкции для работы в репозитории

Игра: «Колокол без Языка», мобильный/браузерный deckbuilder-roguelike. Язык интерфейса и текстов: русский. Комментарии в коде тоже по-русски.

## Стек и команды
- TypeScript (strict), Vite, vitest, vite-plugin-pwa. Без UI-фреймворка: DOM + CSS + SVG.
- `npm run dev`, `npm test`, `npm run typecheck`, `npm run build`, `npm run sim`.
- Перед коммитом: `npm run typecheck && npm test`. Для изменений интерфейса снимай скриншоты (`node scripts/shots.cjs` при запущенном dev-сервере).

## Архитектурные правила
1. **`src/engine` не знает про DOM.** Вся логика боя и забега чистая и детерминированная по сиду (`Rng`). Новые правила добавляй с тестом в `tests/`.
2. **Хроника это душа, забег это тело.** `Chronicle` хранит только знание: страницы, имена, открытые карты, счётчики. Запрещено добавлять в неё постоянные бонусы к силе, здоровью, экономике или стартовой колоде. Это жёсткое требование дизайна, тест в `tests/run.test.ts` его проверяет.
3. **Карты** описаны в `src/engine/cards.ts` через `add({...})`. Текст строится функцией `text(up)`, числа берутся через `v(up, обычное, улучшенное)`. Не больше одного нестандартного правила на карту, текст до ~22 слов.
4. **Страницы** живут в `src/content/pages.ts`. У каждой закрытой карты должен быть источник (страница с `unlocks`). Это проверяется тестом. Поле `requires` защищает от спойлеров.
5. **Враги** в `src/engine/enemies.ts`: `pick(e, c)` возвращает ход по номеру хода врага. Намерения всегда показываются игроку.
6. **Боковой сдвиг:** новые карты не должны быть строго сильнее старых. Дизайн-цель: больше вариантов, а не больше силы.

## Тон и мир
Мрачное фэнтези, сдержанный язык, чёрный юмор в эпитафиях Мёрка. Мир: Ор-Вейл, закат после убийства Короля-Солнце Ардана. Тайна раскрывается в три слоя (см. `docs/GDD.md`). Не раскрывай ответы раньше времени: используй `requires`.

## Визуал
- **Ориентация только горизонтальная.** Сцена всегда 390 дизайн-пикселей по высоте, ширина подстраивается под экран, пустых полос нет (`main.ts`). Размеры в CSS писать в дизайн-пикселях.
- **Стиль: пиксель HD, персонажи-силуэты** (решение автора). Внутреннее разрешение сцены 270 по высоте. Персонажи в `src/art/sil.ts`: чёрная форма из кривых и многоугольников, один контурный свет (`rim`), светящиеся глаза и огонь отдельным цветом (`accent`), анимация по фазе (подол, огонь, фонарь, мигание). Новый враг = новая функция `Draw` и запись в `DEFS`. У каждого свой силуэт и характерная деталь; не копировать чужую геометрию. Не добавлять шум и случайные края: это выглядело грязно.
- **Карты**: иллюстрации собираются из деталей (`PROPS`) по рецептам `RECIPES` в `cardart.ts` (небо с дизерингом, свет, туман). Новая карта = новый ключ `art` + рецепт.
- **Палитра**: уголь `#0b0d12`, индиго, ил, охра, кость `#d9d2c0`, кровь-лак, акцент свечи `#e8a94a` (жизнь и информация).
- **Шрифты**: Press Start 2P (заголовки, кнопки, числа), Handjet (интерфейс), EB Garamond (сюжетный текст). Pixelify Sans не использовать: в кириллице искажены К и д.
- Анимации только как ответ на действие или один важный момент.
